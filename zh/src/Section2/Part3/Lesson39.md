# 用から、そして、ので、で表示理由

から不仅仅是表示"从"的格助词。它也作为接续助词出现，用来连接两个句子，其中から后面的内容是から前面内容的结局或结果。

你可以把接续助词から和格助词から区分开来，因为格助词只出现在名词后面，而接续助词出现在完整的从句后面。这意味着要把表示"因为"的から接在名词和な形容词后面，就必须加上だ（或です）。它也可以直接接在动词和い形容词后面（格助词から做不到这一点）。

A(だ)からB 大致的意思是"因为 A，所以是 B"。

<pre>
暑い<b>から</b>プールに行きたいです
<b>因为</b>很热，<b>所以</b>我想去游泳池

みんないい人<b>だから</b>、きっと気にいる
他们都是好人，<b>所以</b>你一定会喜欢他们的。
</pre>

から可以以だから的形式出现在句子开头。在这种用法中，它既可以表示强调，也可以为前面的陈述给出解释。

<pre>
<b>だから、</b>そんなこと言わないでください。
<b>我都说了</b>，请不要说那种话！
</pre>

ので的作用与から相似。在名词和な形容词后面，它变成なので或ですので。

から和ので之间有一些语感上的差异，但大意是から听起来更像主观意见，而ので感觉更客观。因此，在礼貌的场合，から可能会显得咄咄逼人，人们往往更喜欢用ので。

<pre>
外は暑い<b>ので</b>気をつけてください
外面很热，<b>所以</b>请小心。

大事なこと<b>なので</b>、二回言いました。
<b>因为</b>是重要的事情，<b>所以</b>我说了两遍。
</pre>

で可以作为类似于"所以"的接续词使用。它建立了一种较弱的原因 -> 结果关系。で接在名词和な形容词后面。对于动词和い形容词，要把它们活用成て形来达到同样的效果。

<pre>
突然のこと<b>で、</b>すぐに理解できなかった
事情太突然了，<b>所以</b>我没能马上理解。
</pre>

で的这种用法也可以出现在陈述句的开头，用来承接前面的陈述，有时以それで的形式出现：

<pre>
<b>それで、</b>これからどうするの？
<b>那么</b>，接下来你打算怎么办？
</pre>

そして是一个接续词，它基本上给人一种终结感，作为一系列依次发生的陈述中的最后一个元素（像"最后……"），或者给出一个结论性的理由（"于是……"）。它可能听起来很正式。

<pre>
<b>そして、</b>ついにその日が来た。
<b>然后</b>，那一天终于到来了。

<b>そして、</b>ありがとうございました。
<b>最后</b>，谢谢大家。
</pre>
