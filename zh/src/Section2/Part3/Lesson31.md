# 副词

副词是用来描述动词、形容词甚至其他副词的词。它们提供额外的信息，比如动作是以什么方式进行的。在中文里，"请多多地加糖"中的"多多地"就是一个副词。

日语有"真正的"副词（副詞），它们可以不带任何特殊的助词或标记使用，并且可以放在句子中（几乎）任何位置。

<pre>
<b>まったく</b>意味がわからない
我<b>完全</b>搞不懂

<b>全然</b>ダメだった
<b>根本</b>没用
</pre>

这两个例子使用的都是"真正的"副词。如果我们把第一句改成意味が**まったく**わからない，意思不会有任何变化。这些词有时可能看起来像名词，但关键的区别在于它们不被助词标记。有时它们*也*可以作为名词使用。像量词这样的特殊词也是副词。我们会在后面的课程中进一步了解量词。

除了这些"真正的"副词之外，还有其他使用特殊活用或助词的类型。

と副词是加上と变成副词的词。

<pre>
<b>自然と</b>殺す
<b>自然而然地/本能地</b>杀

<b>次々と</b>出てきます
它们<b>一个接一个地</b>出现了。
</pre>

同样，に副词是加上に的词。

<pre>
<b>自由に</b>勉強する
<b>自由地</b>学习

<b>本当に</b>いいですか？
<b>真的</b>可以吗？
</pre>

に副词原本通常是名词或な形容词。对于后者，只需把な变成に即可。

<pre>
<b>自然な</b>言い方
<b>自然的</b>说法

<b>自然に</b>言う
<b>自然地</b>说
</pre>

你可能已经从上一个例子中注意到，な形容词自然既可以作と副词，也可以作に副词。这并不少见，因为词语可以有多种角色和用法。在这种情况下，两者有细微的语感差异，很难解释。只要记住，与に相比，と常常听起来更正式或更书面一些。

很多被教科书视为"语法点"的表达，其实只是在名词或名词短语后面加上作为副词标记的に，以提供额外的含义。

就像な形容词变成に副词一样，い形容词也可以通过把い换成く来变成副词。

<pre>
<b>早く</b>起きる
<b>早</b>起
</pre>

有些と副词可以接动词する，变成描述存在状态的动词。这种用法常常是惯用的，并且仅限于特定的活用形式（比如した、している等）。

<pre>
車内は<b>広々としていた</b>。
车内<b>很宽敞</b>
</pre>
