# 用みたい、らしい、ぽい和そう表示相似与传闻

日语中有很多方式来表达"X 像 Y"或"X 看起来像 Y"。

其中之一是な形容词后缀みたい。它看起来像見る的たい形 -> 見たい，但在现代日语中，它被认为是完全不同的东西，不应该混淆。

みたい（它**总是**用假名书写，**绝不**应该写成見たい）是一个な形容词，也像な形容词一样活用。它的意思是"好像"。

<pre>
あの人、日本人<b>みたい</b>
那个人，好像是日本人 / 他看起来像日本人

ヒーロー<b>みたいな</b>人
像英雄一样的人
</pre>

虽然みたい实际上完全是一个な形容词，但在作状语使用时，它有时会像い形容词一样活用。这被视为随意/俚语的说法，但你会在日语媒体中经常看到它，所以最好知道它的存在。

<pre>
子供<b>みたいに</b>ブランコに乗っている
子供<b>みたく</b>ブランコに乗っている
他像个孩子一样荡着秋千
</pre>

这两个例子都是正确的，但前者更规范。

らしい是一个补助形容词，接在名词或动词/形容词后面，表示根据情况，某件事在事实上"似乎是这样"。らしい适用于可以翻译为"似乎是 X"而不是"有点 X"的东西。

<pre>
日本人<b>らしい</b>名前。
一个像是日本人的名字。
</pre>

你也可能会看到らしい用来表示"我听说"，用来传达传闻或从第三方获得的信息。

<pre>
出発は明日の昼頃になる<b>らしい</b>。
<b>听说</b>出发时间是明天中午左右。
</pre>

ぽい/っぽい是一个い形容词后缀，表示根据外表或刻板印象中的特征，某样东西在主观上"似乎是这样"。它可以很好地翻译为"有点 X"或"X 似的"。它听起来很随意。

<pre>
今、僕の名前、女<b>っぽい</b>って思ったでしょ？
你刚才觉得我的名字<b>有点</b>像女孩子，对吧？（字面意思："女性似的"）
</pre>

补助后缀そう有两种不同的用法。

第一种接在动词或形容词的ます词干后面，意思是"看起来好像"。它用来从主观的印象或视角描述事物，常常是根据外观。そう会把它所接的东西变成な形容词。

<pre>
おいし<b>そう</b>なスープです。
一碗看起来很好喝的汤。
</pre>

<div class="warning">
不要把かわいそう（可怜）这个词和かわいい（可爱）的そう形混淆。かわいい没有そう形。如果你想说某样东西看起来很可爱，可以用かわいくみえる。
</div>

另一种そう接在它前面的词的完整形式后面，所以对于な形容词和名词，它变成だそう。这种用法的意思是"我听说"，与我们前面看到的らしい的传闻用法相似。它感觉更正式一些。

<pre>
2000人以上が死んだ<b>そう</b>です。
我<b>听说</b>有 2000 多人死了。
</pre>
