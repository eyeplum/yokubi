# 疑问词：なに、だれ、どれ、いつ等

这些词被称为疑问词。它们用来提出特殊疑问句（"什么""谁"之类的问题）。它们有时也会作为更大的语法结构或固定表达的一部分出现。

| 汉字| 读音     | 意思 | 例句（日）             | 例句（中）                    |
|------|-------------|---------|--------------------------|---------------------------------|
| 何   | なに        | 什么    | 何する？                 | 你要做什么？               |
| 誰   | だれ        | 谁     | あなた、誰？             | 你是谁？                    |
|      | どれ        | 哪个   | どれがいいと思いますか？ | 你觉得哪个好？ |
|      | いつ        | 什么时候    | 次の電車はいつですか？   | 下一班电车是什么时候？         |

还有很多其他的疑问词，它们的用法都很相似，所以我们不会把它们全部列出来。如果你还记得关于こそあど词的那一课，こそあど中的ど指的就是这些词。

提问时要记住的一点是，**绝对不要**用助词は来标记这些词。唯一的例外是一些固定表达，比如何はともあれ，但这些真的一只手就数得过来。

<pre>
昨日は誰<b>が</b>来たの？
昨天谁来（这里）了？
</pre>
