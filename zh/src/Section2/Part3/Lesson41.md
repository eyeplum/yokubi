# 数东西

现在我们来谈谈数东西。当你想要说明数量时，通常不能在句子中间使用"自由"的数字。你需要把它们与一个描述你所定义的数量类型的特殊词语搭配起来。这些特殊的词语被称为"量词"（助数詞），而且有**非常多**。有些极其具体，会根据你所数的东西而变化，但也有一些更为通用，规则也不像你可能以为的那样严格。

这就和中文一样：你不能说"我吃了三面包"，而必须说"我吃了三**个**面包"或"三**片**面包"。对于大多数可数的东西，日语都是这样运作的。中文读者在这一点上有天然的优势。

最常见的量词是つ，不过つ也很特殊，因为它不会超过 9。如果你需要数超过 9 个"一般的"东西，就需要使用另一个量词（常常是個，但你不能总是对所有东西都用個）。

| 数字 | 读音                                          |
|--------|--------------------------------------------------|
| 一つ　 | ひとつ                                           |
| 二つ　 | ふたつ                                           |
| 三つ　 | みっつ                                           |
| 四つ　 | よっつ                                           |
| 五つ　 | いつつ                                           |
| 六つ　 | むっつ                                           |
| 七つ　 | ななつ                                           |
| 八つ　 | やっつ                                           |
| 九つ　 | ここのつ                                         |
| 十　　 | とお（这是一个例外，它不是量词） |

正如你所看到的，这些词的发音学起来极其烦人。不要试图把这些全部背下来，只要知道它们的存在，并通过沉浸去接触它们就行了。其他很多量词也是如此，比如日（日）、月（月）、年（年）、年龄（歳/才）等等。它们的读音极其不规则。

说到年龄，有一个有趣的例外：年龄有时会直接用数字来表示，而不带量词：

<pre>
ボクはまだ<b>12</b>ですよっ！
我才 12 岁啊！
</pre>

如果你还记得之前的一课，量词的作用就像副词，可以像副词一样放在句子中几乎任何位置。此外，和副词一样，量词不能被格助词标记。尽管它们看起来像名词，但它们并不是名词。

<pre>
二人、兄弟がいる
兄弟が二人いる
我有两个兄弟
</pre>

这两个句子的意思是一样的（但后者更常见）
