# 修饰疑问词的か、も和でも

除了标记疑问之外，か还可以用来把疑问词变成泛指的名词。

|            |               |
|------------|---------------|
| なに       | 什么          |
| なに**か** | **某个**东西 |

<br />

|            |             |
|------------|-------------|
| だれ       | 谁         |
| だれ**か** | **某个**人 |

<br />

|            |               |
|------------|---------------|
| どこ       | 哪里         |
| どこ**か** | **某个**地方 |

<br />

|            |                           |
|------------|---------------------------|
| いつ       | 什么时候                      |
| いつ**か** | **某个**时候（总有一天） |

なにか常常被含糊地说成なんか：

<pre>
<b>なんか</b>飲む？
你要喝<b>点什么</b>吗？
</pre>

一定不要混淆下面这两种用法：

<pre>
何<b>が</b>あった？
发生了什么？（字面意思：有什么？）

何<b>か</b>あった？
发生什么事了吗？（字面意思：有什么东西吗？）
</pre>

注意，在疑问词 + か的后面，通常会省略助词が（何かが -> 何か），可能是因为这样更容易发音。

同样地，我们也可以用も把疑问词变成"包含性/排除性"的名词。想想中文里的"任何东西"或"什么都没有"这样的词。

|        |                          |
|--------|--------------------------|
| なにも | 什么都/什么都不         |
| だれも | 每个人/任何人/谁都不   |
| どれも | 哪个都/哪个都不 |
| いつも | 随时/从不/总是     |

<pre>
ここは何<b>も</b>ない
这里<b>什么都</b>没有

誰<b>も</b>が知ってること
<b>每个人</b>/<b>任何人</b>都知道的事。

いつ<b>も</b>そんなことを考えてるの？
你<b>一直</b>都在想那种事吗？
</pre>

注：当誰も在非否定的陈述中用作主语时，が不能省略，所以要说成誰もが

"每一个特定的东西"和"任何一个特定的东西"之间存在逻辑上的区别。通过在其中一些词后面加上でも，可以赋予它们"任何一个特定的东西"这种"任何"的含义。

<pre>
あんたは誰<b>でも</b>助けるの？
你（真的）会救<b>任何人</b>（不管是谁）吗？

場所はどこ<b>でも</b>いい。
<b>哪里</b>（不管在哪里）都可以
</pre>
