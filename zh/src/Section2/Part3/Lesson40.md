# 用より和の方が进行比较

より用来直接比较两样东西，就像"我比你聪明"中的"比"。使用より时，你不需要使用表示"更"的词，这一点与英语不同，英语需要说"**more** X than Y"或"X**er** than Y"。这和中文的"比"很像。有时より后面可以接も来加强语气。

<pre>
彼は誰<b>より</b>も強いよ
他<b>比</b>任何人都强
</pre>

在这个例子中，不带も的誰より可能会显得奇怪，也不太常见。

より也用于表示相对位置（空间或时间上）的句式中，类似于から。

<pre>
南<b>より</b>迫る
<b>从</b>南方逼近

新世界<b>より</b>
<b>来自</b>新世界
</pre>

より的这种用法在书信中很常见，より标记寄信人，へ标记收信人。

如果你想把比较的双方都列出来，就用より标记较低的一方，用方标记较高的一方。方是一个名词，在这种用法中读作ほう（不要被かた这个读音骗了！），和所有名词一样，它通过の接在其他名词后面，后面也可以接助词。在比较的情况下，无论方这一"边"是不是动作的主语，通常都用が来标记。

<pre>
メリット<b>より</b>もデメリット<b>の方が</b>大きい
缺点<b>比</b>优点<b>更</b>大。
</pre>

如果隐含了より这一边，可以省略它。

<pre>
私は一人で行動する<b>方が</b>性に合っている。
对我来说，一个人行动<b>更</b>合我的性子。
</pre>

从字面上看，方的这种用法标记的是比较的一"边"。XよりYの方がZ 可以理解为"**从** X 这一边出发，Y 这一边**更** Z"，其中 X 是较低的一方，Y 是较高的一方。

有一些惯用表达使用了方が。

〈动词〉方がいい的意思是"做〈动词〉比较好"。在这个句式中，如果陈述是出于个人建议而不是一般真理，通常会使用动词的过去时。

<pre>
やめ<b>た方がいい</b>と思います
我觉得你<b>最好</b>还是别做了。

少し余裕があ<b>る方がいい</b>だろう。
我想还是留一点余地<b>比较好</b>吧。
</pre>

当いい以过去时活用，比如方がよかった时，它暗示了对过去本应做或不应做的某个动作的一些后悔或责备。

<pre>
真面目に戦っ<b>た方がよかった</b>のだろうか。
如果我认真战斗的话，会不会<b>更好</b>呢？
</pre>
