# 用わけ、はず、べき、ものだ和かもしれない表示预期

わけ是一个表示"理由"（"为什么"的那个理由）的名词。它可以用于许多不同的固定表达中。这里不可能把它们全部列出来，只列举几个常见的。

从本质上说，わけ(だ)陈述的是理由、解释、事实、逻辑上的重述或结论。这种用法偶尔可以用のだ来代替。

<pre>
なるほど、そういう可能性もある<b>わけだ</b>。
原来如此，所以也有那种可能性啊。

それならいくら探しても見つからない<b>わけだ</b>。
如果是那样的话，难怪他们怎么找都找不到她。
</pre>

わけがない的意思是"不可能"，暗示说话者连想都想不到会有这种事

<pre>
そんな馬鹿なことがある<b>わけがない</b>。
<b>不可能</b>有那么荒唐的事。
</pre>

另一方面，わけじゃない是一种拐弯抹角地否定某种情况、状况或逻辑结论的方式。

<pre>
可能性がない<b>わけじゃない</b>。
<b>并不是</b>完全没有可能。
</pre>

わけにはいかない的意思是，根据一般常识或社会期望，某件事是不可能的。

<pre>
このチャンスを逃す<b>わけにはいかない</b>。
我<b>绝不能</b>放过这个机会。
</pre>

由于わけ是一种非常强烈的陈述，它常常与という搭配，以というわけ的形式出现，来缓和表达的冲击力。

はず表示说话者预期某件事在事实上是真的或将会成真。它可能类似于中文的"应该"，但并不涵盖完全相同的全部情况。はず还暗示这种预期是基于推理的，而不是纯粹的猜测。

<pre>
こんな<b>はず</b>じゃなかった、こんな<b>はず</b>じゃなかった
<b>不应该</b>是这样的，<b>不应该</b>是这样的

さっきまで自分の部屋にいた<b>はず</b>なのに。
可她刚才<b>应该</b>还在自己房间里的啊……

その場にいた全員がそう思った<b>はず</b>だ。
在场的所有人<b>一定</b>都是这么想的。
</pre>

べき表示说话者期望某种行为或状态得到维持，因为不这样做会很糟糕、不负责任等等。

<pre>
この場から立ち去る<b>べきだ</b>。
<b>应该</b>离开这个地方。

わからないことは聞く<b>べきだ</b>。
不懂的事情<b>应该</b>问。
</pre>

不过，在某些情况下使用べき并不总是那么沉重，尤其是在疑问句中征求某人的见解或建议时。

<pre>
どこに行く<b>べき</b>だと思う？
你觉得我们<b>应该</b>去哪里？
</pre>

当它是过去时，比如べきだった时，表示某个动作或状态"曾经是"或"本来会是"正确的，通常是后者。

<pre>
もっと気を付ける<b>べきだった</b>。
我们<b>本应该</b>更小心一些的。
</pre>

べし是べき的古语版本。只要知道它的存在就行了。

ものだ也可以表示"应该"，其语感是一种适用于很多人的一般性的"应该"，而不仅仅是针对某个特定的人或群体。它常常用来陈述"事物本来就是这样"的性质。

<pre>
子供は親の言う事を聞く<b>ものだ</b>。
孩子<b>就应该</b>听父母的话。
</pre>

かもしれない是一个复合的句末表达。它的接续方式与单独的か相同。它表示说话者认为这个陈述是一种可能性。有时人们出于礼貌，会把它加在自己明知是真的事情上。

<pre>
まだ寝ぼけている<b>かもしれない</b>。
她<b>也许</b>还没完全睡醒。
</pre>

在随意的对话中，かもしれない常常简略为かも。
