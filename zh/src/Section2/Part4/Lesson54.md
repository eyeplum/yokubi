# 用なる和する表示"变成"与"使成为"

我们已经在前面几课的一些例子中见过なる了。现在我们来更深入地看看它是如何运作的。

なる是一个动词，意思大概是"变成"或"最终成为"。除了单纯的"变成"之外，它还可以用于各种间接的状态，比如一个团队最终由哪些成员组成，或者一个谣言结果是真的。

<pre>
海賊王<b>に</b>俺は<b>なる</b>！
我要<b>成为</b>海贼王！

1500円<b>になります</b>
一共是 1500 日元。
</pre>

に用作标记主语所"变成"的名词（或东西）的助词。和往常一样，助词的顺序可以改变强调的重点，正如我们在上面第一个例句中看到的那样。

不过，实际上，なる接的是一个副词，而不仅仅是用に标记的名词。只是恰好名词（和な形容词）在使用に时可以变成副词性的。

当我们试着把なる和い形容词一起使用时，就可以证实这一点。要做到这一点，我们需要像这样把它们变成副词：

<pre>
これからもっともっと強<b>くなる</b>。
从现在起，我会<b>变得</b>更强、更强。
</pre>

否定（ない）形也是如此：

<pre>
食事が美味しく<b>なくなる</b>
饭菜<b>变得不</b>好吃了
</pre>

甚至动词也可以和なる搭配。否定形的动词像い形容词一样活用，たい形的动词也是如此。与此同时，普通形/非否定形的动词则需要一个额外的辅助名词，比如よう，它的大致意思是"以……的方式"（和我们在[第 42 课](../Part3/Lesson42.md)中已经见过的よう相同）。

<pre>
たこ焼き食べた<b>くなった</b>。
我<b>变得</b>想吃章鱼烧了

ここで下がれば本当に道がわから<b>なくなる</b>。
如果从这里下去，就真的<b>会</b>找不到路了。

見えなかったものが見える<b>ようになる</b>。
原本看不见的东西<b>变得</b>能看见了
</pre>

在ようになる这个结构中，动词常常使用可能形，表示"变得能够做"某事。

作为〈副词〉+ なる的对应，我们现在来看看〈副词〉+ する。

你可以把する看作なる的"主动"版本。〈副词〉+ なる的意思是"**变成**〈副词〉"，而〈副词〉+ する的意思是"**把**（某物）**变成**〈副词〉"。

句子结构与なる完全相同，只是我们用を来标记被"变成"的东西。

<pre>
みんなが目を丸<b>くする</b>。
大家都惊讶地瞪大了眼睛（字面意思："把眼睛变圆"）

彼女は笑みを深<b>くする</b>。
她的笑容更深了（字面意思："把笑容变得更深"）

美味しいものは人を幸せ<b>にする</b>。
好吃的东西让人幸福（字面意思："把人变成幸福"）
</pre>
