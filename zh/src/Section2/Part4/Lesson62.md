# 用後、前、先和時表示时间关系

後是一个表示"之后"的名词。X後で是一个接续表达，表示某件事在 X 之后发生，但不一定是紧接着发生。

<pre>
昨日は夕食を食べた<b>あとで</b>、すぐに部屋に戻った。
昨天，吃完晚饭<b>之后</b>，我们马上就回房间了。
</pre>

前是後的反义词，意思是"之前"。前既可以表示空间意义上的"前"（即在你前面），也可以表示时间意义上的"前"（即过去）。由于"把过去抛在身后"这种观念，这一点可能有点违反直觉，但如果你想想排队等候的人群，排在你*前面*的人会比你*先*轮到。所以当轮到你的时候，他们的那一轮已经*过去*了。中文的"前"其实也同时有这两种意思（"面前"和"以前"），所以中文读者应该很容易理解。

接续表达X前に表示某件事在 X 发生之前发生，但不一定是紧挨着之前。如果 X 是动词，它**不能**是过去形。

<pre>
考える<b>前に</b>、体が動いていた。
在思考<b>之前</b>，我的身体就已经动了。
</pre>

前和先几乎是同义词。

先是一个名词，意思是"之前""前方"或"前端/尖端"。一般来说，当先表示空间时，它指的是某物的前端（"尖儿"），或者它所朝的方向，而不是紧挨在它前面的位置。

<pre>
目線の<b>先に</b>は、少女がいた。
我的眼<b>前</b>有一个少女。（字面意思："在我视线的前方"）
</pre>

和前一样，它也可以表示时间上的"之前"。

<pre>
それは<b>先に</b>言った。
那个我<b>之前</b>说过了。
</pre>

さっき是先的随意版本，专门用来表示"刚才"。

時是一个表示"时间"的名词，但如果你给它加上一个关系从句，它就可以起到接续表达的作用（"……的时候"或"在……之时"）。

<pre>
そんなことを考えている<b>時、</b>宿屋の入り口で大声が聞こえた。
<b>正当</b>我想着那件事的<b>时候</b>，听到旅馆门口传来一阵很大的声音。
</pre>

动词 + 時的表现会根据它前后陈述中动词的时态而有所不同。有各种规则，但一般来说，如果時前面的动词是过去时，就意味着時后面的动作是在前面的动作已经完成时发生的。不过不要试图去记这些规则，只要在学习过程中学会识别它们就行了。

<pre>
目が覚め<b>た時</b>、俺は知らない場所にいた。
<b>当</b>我醒来<b>的时候</b>，发现自己在一个陌生的地方。
</pre>
