# 表示遗憾与安心的补助动词てしまう和ておく

てしまう表示某件事"完成了"或"彻底做完了"。它也用于事情"最终"落入这样一种"完成"的状态时，比如犯错之后。记住它的一个好方法是想想"搞定了"和"这下可糟了"。它常常带有遗憾的语感。

在口语中，てしまう也可以说成ちまう或ちゃう（对于浊音的动词活用，比如死んでしまう -> 死んじゃう，则说成じゃう）。

<pre>
私はあっという間に全部食べ<b>てしまった</b>。
我一眨眼的工夫就把它全<b>吃光了</b>。

私は死ん<b>でしまった</b>みたいです。
看来我是死了（字面意思：<b>最终</b>死掉了）
</pre>

一旦某件事用てしまう做完了，其含义就是它无法挽回了。

ておく的意思是做了某件事之后，就把它放在那里不管，期待它将来会有所收获。这常常被描述为"事先做好准备"，因为实际上它常常就是这个意思。它也可以比喻地表示"做了某件事，然后就把它抛到脑后"。ておく常常缩约为とく

<pre>
まず最初に言っ<b>ておき</b>たいことがある。
首先，有件事我要先跟你说清楚。

俺はただ知って<b>おきたい</b>だけなのだ。
我只是单纯地想先知道一下而已（= 为了让自己安心）
</pre>
