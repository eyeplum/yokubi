# 用ころ和くらい表示"大约"，用まで、ほど、すぎる表示限度

ころ是一个名词，大致的意思是"大概的时间"。你会经常遇到Xのころに。这既可以是一个接续表达，意为"在 X 的时候前后"，也可以是一个名词，意为"X 的那段时期"，后面加上了助词に。在某些情况下，ころ可以作为后缀ごろ直接接在名词后面。

<pre>
子供<b>のころに</b>見たアニメを思い出す。
我想起了<b>小时候</b>看过的动画。

そういえば、去年の<b>今ごろ</b>だったかな？
对了，好像是去年<b>这个时候</b>吧？
</pre>

くらい接在一个量度或数量（包括时间）后面，使其变得大约。它与ぐらい完全可以互换，完全取决于说话者的喜好。

<pre>
午後1時<b>ぐらい</b>で大丈夫？
下午 1 点<b>左右</b>可以吗？
</pre>

它也可以用来表示"到……的程度"或"到……的地步"，而且一点也不超过。

<pre>
毎日食べたい<b>くらい</b>美味しかったです
好吃<b>到</b>我每天都想吃<b>的程度</b>。
</pre>

与助词は搭配时，它带有"至少"的语感。

<pre>
名前<b>くらいは</b>聞いたことがあるだろう。
你<b>至少</b>听说过它的名字吧。
</pre>

まで的基本意思是"直到"或"到……为止"。まで所标记的界限或边界包含在范围之内。

<pre>
世界が終わる日<b>まで</b>。
<b>直到</b>世界终结的那一天。
</pre>

まで常常与から搭配，构成〜から〜まで（从〜到〜）。

<pre>
小さなこと<b>から</b>、大きなこと<b>まで</b>。
<b>从</b>小事<b>到</b>大事。
</pre>

までに把まで的意思变成"在……之前"（比如"在下周五之前完成某事"）

<pre>
明後日<b>までに</b>は終わらせます。
我会<b>在</b>后天<b>之前</b>完成。
</pre>

ほど在比较方面的基本意思是"像……那样"。归根结底，ほど的核心含义是"到……的程度"。

<pre>
私は彼ら<b>ほど</b>強くない。
我没有他们<b>那么</b>强。
</pre>

在肯定的陈述中，当ほど接在一个"数量"后面时，它表示大约。

<pre>
中身はまだ半分<b>ほど</b>残っている。
里面的东西还剩<b>大约</b>一半。
</pre>

すぎる是一个动词，意思是"超过"或"超越"。作为补助动词，它的意思是"太……了"，或者表示行为过度。它接在ます词干后面。

<pre>
美味しいものを食べ<b>すぎた</b>。
我好吃的东西吃<b>得太多了</b>。
</pre>
