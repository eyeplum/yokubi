# 用〜たり〜たり和ては列举与重复动作

我们已经在[第 36 课](../Part3/Lesson36.md)中看到，可以用列举助词とか来构成动词的**非完全**列举。

たり是另一个可以以类似方式使用的助词/活用形式。实际上，这样使用たり比使用とか更常见，也更口语化。

动词的たり形就是过去时 + り：

| 辞书形 | 过去   | たり形 |
|------------|--------|-----------|
| 食べる     | 食べた | 食べたり  |
| 飲む       | 飲んだ | 飲んだり  |
| 切る       | 切った | 切ったり  |
| 死ぬ       | 死んだ | 死んだり  |

在一串〜たり动作的末尾，自然地会接上动词する，它把整个动词块变成一个可以活用的短语，其表现就像一个巨大的动词。

<pre>
手をつない<b>だり</b>、抱きしめあっ<b>たり</b>、キスをし<b>たり</b>したいから。
因为我想<b>做些</b>牵手啦、拥抱啦、接吻<b>之类的事</b>。
</pre>

与用て形串联动词不同，たり不假定动作有任何严格的顺序或先后。它只是说明这些动作中的任何一个（甚至是其他没有说出来的动作）以任意的顺序发生。AてB 大致的意思是"做 A，然后做 B"，而 AたりBたりする 的意思是"做 A 啦 B 啦之类的事"。

除了最基本的解释之外，它还有其他一些特定的惯用用法。它可以用来：

- 缓和陈述的语气；
- 增添一种语感，表示你所说的内容会让听者感到意外；
- 陈述经常发生的事情；
- 陈述很可能的可能性。

たり的这些惯用用法有时会互相重叠，所以要准确地指出哪种用法是哪种并不容易。

和其他非完全列举助词一样，它也可以只用于列举中的一个元素。

<pre>
笑っ<b>たりして</b>ごめんなさい。
对不起，我笑了。

実はそう<b>だったりする</b>
其实，还真是那样。

昔はよく一緒に遊ん<b>だりしました.</b>
我们以前经常一起玩。

もしかしてお金が必要<b>だったりする</b>のだろうか？
难道说，你可能需要点钱吗？
</pre>

〜たり〜たり也可以用来突出两个交替重复发生的动作。在这种用法中，两个动作常常是自然的对立面，而且这组たり的末尾不使用する动词。

<pre>
大きくなっ<b>たり</b>小さくなっ<b>たり</b>。
它变大，又变小，又变大，又变小……
</pre>

ては活用形也可以以类似的方式使用。

<pre>
飲ん<b>では</b>笑い、笑っ<b>ては</b>飲む。
他喝了就笑，笑了又喝。
</pre>
