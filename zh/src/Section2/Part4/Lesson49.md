# とする的多种用法

とする主要有四种用法。第一种表示某人假定/假设某件事，与陈述句一起使用。可以把它理解为"假装/当作"。作为邀请时最容易看出这一点，但它也可以是一个关于别人的假定的更长句子的一部分。

<pre>
それが本当だ<b>とすれば</b>どうなるのだろうか。
<b>假如</b>那是真的，会怎么样呢

誰かが呼びに来た<b>としても</b>不思議ではない。
<b>即使</b>有人来这里叫（我们？），也不奇怪。
</pre>

第二种是として这个补助成分，具有一般性的、模糊的"作为 X 而运作"的意思。这与第一种用法直接相关，可以把它理解为"把 Y 当作 X 来看待"。在这种用法中，它通常直接接在名词后面。

<pre>
その判断は医者<b>として</b>間違いではなかった。
那个判断，<b>作为</b>医生来说并没有错。
</pre>

第三种用法表示某样东西经历了一种"体验性"的状态，基本上与つるつる"滑溜溜"这样的"拟态"词一起使用。拟态词是指表示声音的词（拟声词）或类似声音的属性的词。

<pre>
頬がぴりっ<b>とする</b>。
我感到脸颊一阵刺痛。
</pre>

最后，とする可以出现在意志形的动词后面。这可以赋予它两种不同但常常相似的含义。

第一种含义是某件事"即将发生"。既可以是主语所控制的意志性动作，也可以是不由自主、无法避免的事情（比如自然现象等）。

<pre>
本部を出て行<b>こうとした</b>時、アルフォンスに呼ばれた。
我<b>正要</b>离开总部的时候，被阿方斯叫住了。

そんな時間も終わりを迎え<b>ようとしている</b>。
那样的时光也<b>即将</b>走到尽头。
</pre>

另一种含义更接近于"试图做某事"，只能用于有意的动作。

<pre>
本気で僕を食べ<b>ようとしている</b>らしい。
它好像是真的<b>想要</b>吃掉我。
</pre>

当动词是有意的动作时，"即将"和"试图"这两种含义之间的界限有时会很模糊。想一想，如果你试图做某事，却因为被打断而失败了，那么你也是正要去做它。所以这个结构可以同时具有两种含义：

<pre>
俺が再びご飯を食べ<b>ようとした</b>時、ガタッと音がする。
我<b>想</b>再次吃饭的时候，听到了一阵咔嗒声。
我<b>正要</b>再次吃饭的时候，听到了一阵咔嗒声。
</pre>
