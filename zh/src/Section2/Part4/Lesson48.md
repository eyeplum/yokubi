# 用いい表示许可与用ませんか表示否定式邀请

いい的意思就是"好"或"可以"，它本身并不是一个语法术语，但经常用于表示许可的句型中。接在て形后面，它就是在请求允许做て所标记的动作。てもいい的作用也基本相同，这两种你都会经常看到。

<pre>
食べて(も)<b>いい</b>？
我可以吃吗？
<b>いい</b>よ
可以啊
</pre>

当人们使用よかった时，他们通常是在表达高兴，而不是"好"。よかった不应该用于表示许可。

<pre>
来てくれて<b>よかった</b>
你能来真是太好了。
</pre>

当涉及否定时，带いい的"许可"陈述常常游走于许可和请求之间，就像过分礼貌的中文或英语一样。说到否定 + ていい，ないで(も)いい和なくて(も)いい的意思大致相同，基本上可以互换。なくて(も)いい更常见。

<pre>
食べなくて(も)<b>いい</b>よ
不吃也没关系哦
</pre>

作为回答时，いい(です)通常表示拒绝的意思（就像中文里的"不用了"）。

<pre>
レジ袋ご利用ですか?
您需要袋子吗？
いや、<b>いいです</b>
不，不用了。
</pre>

在之前的一课中，我们看到意志形可以用来邀请/催促某人和你一起做某事。还有另一种方法可以问某人是否想和你一起做某事，那就是用否定形式来提问。这类似于中文里的"要不要……？"或"不……吗？"

<pre>
明日、映画を見に<b>行かない</b>？
明天要不要一起去看电影？
</pre>

这个结构也可以用于不是邀请的请求。

<pre>
すいません、もう一回言ってくれ<b>ませんか</b>？
不好意思，能再说一遍吗？（字面意思："你不再说一遍吗？"）
</pre>
