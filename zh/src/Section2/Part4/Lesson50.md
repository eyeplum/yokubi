# 用てみる尝试做事

补助成分てみる源自动词見る，这可以为如何记住它的意思提供一些线索。它的大致意思是"试着做某事（看看结果如何）"。这和中文里"做做看""试试看"中的"看"非常相似。不过，当它以这个意思使用时，绝不应该写成汉字。

てみる表示这个动作是"尝试性的"，或者是为了看看这样做会有什么结果而进行的。

<pre>
食べ<b>てみる</b>
我尝尝看（看看怎么样/看看我喜不喜欢/看看有没有毒，等等）

チョコレートケーキを作っ<b>てみました</b>
我试着做了巧克力蛋糕。

想像し<b>てみて</b>ください。
请试着想象一下。
</pre>

在上一课中，我们看到了另一个可以翻译为"试图做"的语法点：ようとする。

在日语中，这两个语法点非常不同，但翻译成中文时常常会引起混淆。てみる假定动作是会去做的，重要的是结果；而ようとする暗示困难的部分（"尝试"）在于动作本身。它常常带有一种假定，即主语一开始就无法"做到"这个动作。

看看这两个句子之间的区别：

<pre>
まずは一度逃げ<b>てみよう</b>
首先，我们<b>试着</b>逃一次<b>看看</b>吧。

僕は、逃げ<b>ようとする</b>彼女の手を取った。
我抓住了<b>想要</b>逃走的她的手。
</pre>

第一句的重点在于说话者不知道他们的逃跑尝试会怎么样，但他们想试试看。第二句中，女孩甚至还没开始逃跑就被阻止了。它暗示她<b>试图</b>开始"逃跑"这个行为，但没能坚持到底。
