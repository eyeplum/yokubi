# 用だけ、のみ、ばかり和しか表示"只"

だけ、のみ和ばかり都是"只"或"仅仅"的变体。しか与它们相似，但只能用于否定的陈述中。

だけ在数量方面表示"只有这么多"。它的作用就像一个助词。

<pre>
俺<b>だけ</b>行く
只有我去

俺<b>だけ</b>じゃないよ
不只是我。
</pre>

のみ就像一个不那么口语化的だけ。

<pre>
味付けは塩コショウ<b>のみ</b>。
调味只用了盐和胡椒
</pre>

ばかり是又一个表示"只"的词。它也可以读作ばっか或ばっかり。Xばかり关注的是落在 X 定义范围内的一切都为真，而だけ和のみ关注的是落在陈述范围之外的东西为假。想想"只有这个"和"没有别的"之间感觉上的差异。

<pre>
悪いこと<b>ばかり</b>じゃないと思います。
我觉得并不全是坏事。

分からないこと<b>ばかり</b>だった
全是我不懂的东西。
</pre>

〈动词〉てばかりいる这个结构常常用来表达对某人的批评态度，说他们只是一遍又一遍地做一件事，以至于到了有害的程度。

<pre>
彼は寝て<b>ばかり</b>いる
他什么都不干，光睡觉
</pre>

ばかり也可以和时间性的陈述一起使用，来表达某件事发生得有多快或多早。

<pre>
戦いはまだ始まった<b>ばかり</b>だ。
战斗才刚刚开始。
</pre>

しか与否定的陈述一起使用，表达与だけ相同的意思，但重点在于除了被标记的东西之外的其他一切。

<pre>
僕<b>しか</b>いない
这里除了我之外没有别人
</pre>

复合形式だけしか也存在。它的作用与しか完全相同，但强调的语气更强。
