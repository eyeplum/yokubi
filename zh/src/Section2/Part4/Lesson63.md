# 再多一点：一些额外的助词和补助成分

作为最后一课，我们来谈谈最后几个没能放进其他任何一课的助词和补助成分。

它们大多是列举助词或强调助词，很难忘记，也很容易找到感觉。就把它们当作临别时赠送给你的最后一份知识礼物吧。

なり可以作为列举标记，标记可能选项的例子。

<pre>
親<b>なり</b>教師<b>なり</b>の指導が必要だ
需要父母<b>或者</b>老师<b>之类的人</b>的指导。
</pre>

きり/っきり是一个补助后缀，有三种含义。
- 在〈名词〉きり这个句型中，它的作用就像"只"的标记。
- 在〈陈述〉きり这个句型中，它的基本意思是"自从〈陈述〉以后（就一直）"。
- 在〈动词词干〉きり这个句型中，它可以表示"把〈动词〉做到底"。

やら是一个有两种含义的助词。它可以像か一样用在疑问句的末尾，但带有一种不确定和情绪上的强调的语感。

<pre>
まったく、何を考えているの<b>やら</b>。
真是的，他们到底在想些什么啊……？
</pre>

它也可以用来列举可能性/例子，就像用于表示选项的か一样。

<pre>
夢の中ならお茶<b>やら</b>お菓子<b>やら</b>出せます。
如果是在梦里，我可以端出茶<b>啦</b>点心<b>啦</b>之类的东西。
</pre>

こそ是一个强调助词，作用很像在中文里重读某个词。换句话说，它实实在在地强调它所附着的任何东西。它常常"盖在"其他助词（比如が、は、を等）上面，把它们隐藏起来。

<pre>
こういう時<b>こそ</b>冷静にならないと
<b>正是</b>在这种时候，我才必须保持冷静。
</pre>

さえ是一个强调助词，根据短语的不同，它的意思是"连 X 都""只要 X"或"只有 X"。

<pre>
私<b>さえ</b>いなければ、こんなことにはならなかった。
<b>只要</b>我不在那里，就不会发生这种事了。

これ<b>さえ</b>あればなんとかなるだろう。
<b>只要</b>有了这个，总会有办法的吧。
</pre>

すら是一个略带书面色彩的强调助词，与さえ非常相似。当さえ的意思是"连 X 都"时，すら可以代替さえ。

<pre>
何が起きたのか<b>すら</b>理解できなかった。
我<b>连</b>发生了什么<b>都</b>无法理解。
</pre>

ずつ是一个表示"每"或"一次……"的助词。它强调某件事的节奏是稳定的。

<pre>
ゆっくり、ゆっくりと、一歩<b>ずつ</b>。
慢慢地……慢慢地……<b>一</b>步<b>一</b>步地。
</pre>

がる是一个补助动词，表示说话者以外的某人表现出某种迹象。たがる是たい和がる的组合，意思是某人看起来想做某事。

<pre>
彼女はそれを知り<b>たがって</b>いた。
她看起来很想知道。
</pre>

がち是一个补助成分，表示某人或某物有某种倾向。从外部的角度来看，这种倾向往往是不好的。

<pre>
後ろから、遠慮<b>がち</b>に声が掛けられた。
身后有人有些迟疑地叫了我一声。
</pre>
