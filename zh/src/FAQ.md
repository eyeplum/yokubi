# 常见问题

这里列出了人们经常问到的**关于本指南**的问题。这些问题**不是**关于学习日语的，而是关于 Yokubi 这个项目的。

### 你为什么要盗用别人的成果？

Yokubi 几乎完全基于 [sakubi](https://sakubi.neocities.org/)，这不是什么秘密。大部分课程、主题以及很多措辞都是直接照搬、改写和重新编排的，但指南的核心仍然是一样的。

然而，我**并没有**盗用 sakubi。Sakubi 是一个开放的项目，是 Sakubi 的作者（我的一位好朋友）原样交给社区的。它以 CC0 许可证发布，属于[公有领域](https://creativecommons.org/publicdomain/zero/1.0/)。此外，Sakubi 项目已经被放弃，自 2018 年以来就没有更新过。如果你还是不相信我，我甚至和原作者谈过，并得到了他对 Yokubi 的祝福。

**Yokubi 是 Sakubi 官方认可的精神续作**

### 和 Sakubi 相比有哪些变化？

我最初试图记录与原版指南相比的所有变化，无论大小。但我写得越多，想改的就越多，以至于现在的结构已经有了很大的不同。不过，我还是可以列出**一部分**变化。这份列表并不完整，但应该能让你大致了解这背后投入了多少工作。

#### 主要变化

- 课程被拆分成 mdbook 格式下的独立页面，而不是单独的一整个网页。这样更便于浏览，也更便于和其他学习者分享单独的课程。
- 放弃了"一形"和"五形"之类的说法，改用一段（ichidan）和五段（godan）这样的动词术语
- 一些课程和语法点被拆分成了单独的课程。Sakubi 有 54 课，Yokubi 有 63 课。
- 新增了一课关于否定的存在状态（state of being）
- 新增了第 0 课，讲解日语句子的结构
- 对若干课程进行了调整和重新排序，使其优先级排序更加合理
- 新增了一节关于する动词的内容
- 新增了一课关于ようとする和てみる的内容（而不是作为可选章节）
- 为たり〜たり新增了一个专门的课程
- 合并了一些"部分"。Sakubi 把第 1 节和第 2 节各分成了若干部分。Yokubi 有 2 节，每节 2 个部分。
- 删除了"插曲"和"隐藏/可选课程"的概念。取而代之的是计划中的附录索引（尚未完成）
- 几乎每一个例句都重新（从日语原生媒体中）选取，并按照难度/适合程度重新排序。除少数例外，例句不会出现尚未讲解过的语法点。

#### 次要变化

- 改变了部分语气和口吻。很多第一人称的写法被改成了更易读的形式。
- 改写了很多语法讲解，减少术语的使用
- 把一些视频和资料的链接换成了更好（更新）的替代品
- 删除了很多有问题的说法，它们要么是错误的，要么主观色彩过强、难以验证其正确性
- 修正了大量错别字和明显的错误

### Yokubi 归谁所有？

Yokubi 项目由 [Morg](https://morg.systems) 发起，项目公开托管在 [GitHub](https://github.com/Morgawr/yokubi) 上。不过，这个项目本身是一个社区项目，欢迎任何人参与讨论、提供反馈和贡献。很多人都在创意、修正、建议、校对、测试等方面提供了帮助。如果你也想加入他们，可以在 GitHub 上提交 issue，或者直接加入我们的 [Discord 服务器](https://discord.gg/KZj4dVFDzu)。

### Yokubi 比其他语法指南好在哪里？

我对这份指南应该是什么样子有着非常强烈的主张。如果你想学日语，外面还有很多其他很棒的语法指南（和教科书）。Yokubi（以及 Sakubi）并不是"最好的"或"终极的"指南之类的东西。它们只是看待问题的一种方式。和它的前身一样，Yokubi 注重（通常）简短、直截了当、非常直接的讲解。它**不会**一路手把手地带着你。它**期望**读者付出一些努力，主动去查资料，并在自己的学习中实现独立。它还**期望**学习者更多地关注沉浸和自然的内容，而不是纠结于语法讲解中最细微的细节。

如果你认为这符合你对日语学习的理解，那就从[开始之前](./Before-you-begin.md)这一页开始学习吧。如果不符合，外面也还有其他指南。**Yokubi 并不指望适合每一个人**。

### yokubi 是什么意思？

就像 [Imabi - 今日](https://imabi.org/) 和 [Sakubi - 昨日](https://sakubi.neocities.org/) 分别是 今日（今天）和 昨日（昨天）的谐音梗一样，Yokubi 是 翌日（第二天）这个词的谐音梗。它同时也是我和朋友之间的一个内部笑话：我们把"yoku"（よく）**错误地**用作 よくある文法 或 よくある言葉（="常见的语法"或"常见的词"）的简称。

就这样，Yokubi 成为了**大众**语法指南。
