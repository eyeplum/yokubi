# 前言

本指南将涵盖理解基础日语所需的大部分语法。它不会讲得过于细致，也不会涉及太多词汇。如果你是在浏览器中阅读，建议安装一个查词扩展，比如 [Yomitan](https://yomitan.wiki/)，这样就可以轻松查询例句中的单词。不过，有些单词本身基本上就是语法，所以它们会在特定的课程中出现。

本指南没有练习题：

- 技能训练式的学习——也就是读一段语法讲解再回答相关问题——在学习一门新语言时是行不通的。
- 很多人被现代教育荼毒，只要有任何需要"做"的东西，大脑基本就会宕机。
- 语法指南是学习词汇的糟糕场所。

如果你想通过日语能力考试，比如 JLPT，那么本指南并不是为你准备的。使用本指南你大概率也能通过，因为通过这类考试所需要的只是具备日语能力，但短期内它很可能会辜负你的期望。本指南中的主题并不是按照 JLPT 的难度排序的，如果你的目标是在短时间内通过较低的级别，那么使用 JLPT 专用的资料可能会更好。

即使是全世界最优秀的语言学家，要解释像"gonna"这样简单的概念，也免不了写出一篇晦涩难懂、长如一本书的论文。这不是哲学问题，而是要解释事物的真正含义或运作方式的问题。简单而不完整的解释是好的，但会有漏洞。本指南尽量在两者之间把握分寸，并对无法解释的地方给出提醒，但这真的很难。作为读者，你需要灵活一些，对这里写的内容"照单全收"。要明白这就是日语**如何**运作的，而追问**为什么**往往不会有什么结果。

本语法指南尽最大努力让你对日语语法有一些基本的接触。它无法**教会**你语法，只能向你介绍语法。你的任务是把这种接触转化为习得。接触只是迈进门槛的第一步。

还有，如果某些内容太难，尽管跳过。你并不是为了应付考试而去记忆某些东西，也不是为了在接触日语内容时能百分之百准确地辨认出它们而去记忆。

你只是想让某些东西进入你的脑海。如果做不到，也没关系，以后你自然会掌握的。

不要回头。
