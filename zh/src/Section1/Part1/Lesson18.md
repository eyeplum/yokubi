# 用いる和ある表示存在，以及である

动词いる和ある表示存在。两者的区别在于主语是否是"会动的"东西。动物和人用いる，而桌子和三明治用ある。像汽车这样会动但没有生命的东西，有时会根据语境和句子的焦点使用其中之一。不要误以为这取决于是否"有生命"。并不是这样。例如，台风用いる，因为它们会自己移动。科幻电影中的机器人也用いる。有时人也可以用ある，特别是在古语和固定短语中。

<pre>
家には猫が<b>いる</b>
家里有一只猫。

店が<b>ある</b>
有一家店。
</pre>

<div class="warning">
ある和いる都是表示存在的动词，在标记存在的地点时，我们通常用に而不是で。
</div>

有时，人们想表达自己有/拥有某样东西时，会用ある或いる。严格来说它们并不是"拥有"的意思，但这与我们在中文里使用"有"的方式是对等的。这只是措辞上的差异。

<pre>
デスクが<b>ある</b>
有一张桌子 / 我有一张桌子

私の家には猫が<b>いる</b>
我养了一只猫。
</pre>

いる按一段动词活用。

<div class="warning">
还有另一个いる动词：要る，意思是"需要"。区别在于这个动词按五段动词活用，所以除了普通形之外，在活用时你可以很容易地把两者区分开来。
</div>

ある按五段动词活用，但它的否定形是不规则的。

|             |
|-------------|
| ある        |
| **ない**    |
| あった      |
| あります    |
| ありません  |

<pre>
店は<b>ない</b>
没有店。
</pre>

既然我们知道了ある，就可以说说だ的起源了：である。である是だ（是）的正式版本。与だ和です不同，である可以用在接在名词前的关系从句中：

<pre>
*友達だ人
（不合语法的胡言乱语）

友達<b>である</b>人
身为朋友的人（正式）
</pre>

你可能还记得，我们用ではない作为だ的否定形。ではない基本上就是である的否定形。

<pre>
である
であった
で(は)ない
</pre>

**注意**：でない也存在，但由于语言的某种特性，在否定である时，加上は的版本已经成为标准/预期的版本。除了"就是这样"之外，没有什么真正的理由。你可能仍然会看到でない，特别是在比较正式的书面媒体或某些固定短语中。
