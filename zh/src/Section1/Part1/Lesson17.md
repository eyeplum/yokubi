# 基础礼貌表达与ます形

现在我们来谈谈礼貌。在日语中，语言的礼貌语气表现为一种特定的语法特征。这意味着当你礼貌地说话时，你构造句子的方式、活用，甚至你选择的词语，都会与随意说话时不同。礼貌有不同的程度，我们在这里只讲基础的内容。

基础的礼貌动词是通过把补助动词ます接在一个词干（通常被称为"ます词干"）后面构成的。对于一段动词，ます接在去掉る的动词部分后面。对于五段动词，把 u 变成 i，然后接上ます。

| 随意     | 礼貌       |         |
|------------|--------------|---------|
| 食べ**る** | 食べ**ます** | 吃  |
| 行**く**   | 行**きます** | 去   |
| 切**る**   | 切**ります** | 切   |
| 歌**う**   | 歌**います** | 唱 |

<div class="warning">
不要在です后面接ます，这是不行的。尽管你可能会在一些作品中看到一些角色故意说不正确的日语时这样用。不要模仿他们。
</div>

在[第 9 课](./Lesson9.md)中，我们提到五段动词的过去时来自"i"词干。虽然对于某些动词（死ぬ -> 死んだ）来说，这个词干在过去形中会出现例外，但在ます中不会出现这种情况。

下面是各类五段动词的过去时和ます形的对比。不要背这个。

| 随意     | 礼貌       | 过去         |
|------------|--------------|--------------|
| 切**る**   | 切**ります** | 切**った**   |
| 殺**す**   | 殺**します** | 殺**した**   |
| 死**ぬ**   | 死**にます** | 死**んだ**   |
| 選**ぶ**   | 選**びます** | 選**んだ**   |
| 読**む**   | 読**みます** | 読**んだ**   |
| 買**う**   | 買**います** | 買**った**   |
| 動**く**   | 動**きます** | 動**いた**   |
| 急**ぐ**   | 急**ぎます** | 急**いだ**   |
| 持**つ**   | 持**ちます** | 持**った**   |

由于ます本身就是一个补助动词，它的结尾和其他动词一样，所以它也可以进一步活用，以表示时态、否定等。不过要注意，否定形的活用是不规则的。

|                  |             |
|------------------|-------------|
| 死にます         | 死      |
| 死にました       | 死了        |
| 死にません       | 不死  |
| 死にませんでした | 没有死 |

ません没有自己的过去时。要给ません加上过去时，就要接上です的过去时でした。

在现代日语中，还有另一种构成动词礼貌否定过去时的方法，那就是直接在非礼貌的否定过去时后面加上です：

| 随意       | 礼貌           |
|--------------|------------------|
| 死ななかった | 死ななかったです |
| 没有死  | 没有死      |

这种用です代替ます的用法可以被视为稍微不那么礼貌，但它已经变得越来越普遍，以至于使用它完全正常，两者之间的区别细微到无法解释。你可以把它们看作是一样的。

ないです和ません也是如此，比如食べないです和食べません。

最后，我们来说说っす，它是です或ます在随意口语中含糊的说法。它没有です那么正式，但起着相同的语法作用。当你想随意一些，但仍然需要遵守です/ます的社交期望时，常常会使用它。有点像穿着商务休闲装去上班。

<pre>
いいです -> いい<b>っす</b>
犬ですか -> 犬<b>っす</b>か
</pre>

っす有时也用来缩约ございます，也就是ある的敬语版本。同样，这去掉了它的正式感，但保留了礼貌。

おはようございます -> おはようっす -> おっす（是的，真的）
