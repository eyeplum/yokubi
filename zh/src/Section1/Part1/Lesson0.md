# 日语句子的结构

当你开始学习一门新语言时——尤其是像日语这样不用空格来标示词语边界的语言——你最大的困惑来源将是如何正确地切分每个句子的各个部分，以便更容易地消化和理解它们。我们把这项活动称为"解析"（parsing）。

无论如何，如果你无法"解析"一个句子，你就无法理解它的意思。如果你不理解它的意思，你就无法习得其中使用的语言。本课将非常简短、快速地介绍一下，要获得基本的"解析"能力需要了解些什么。

日语是 SOV（主语-宾语-动词）语言，而中文和英语都是 SVO（主语-动词-宾语）语言。

<pre>
中文：我吃苹果
日语：我苹果吃
</pre>

一开始这可能看起来很奇怪，但随着你接触越来越多的语言，你很快就会习惯这种"颠倒"的结构。此外，例外情况也有很多，这个语序并不是规则，而只是一个大致的倾向。

日语有两种基本的句式。几乎每个句子都会是"A 是 B"或者"A 做 B"的形式。或者按照日语的语序，是"A B 是"和"A B 做"。我们将在下一课中学习如何构造"A B 是"类型的句子，之后还会学习"A B 做"类型的句子。然后，我们将学习如何把它们连接、串联起来。

日语的另一个特点是，它是一种"代词脱落"（pro-drop）语言。这意味着任何可以从上下文中暗示或理解的东西都可以省略。例如，如果主语是谁很明显，我们就不需要再说一遍。"苹果吃"是一个完全没问题的句子，只要我们知道它所指的主语是"我"。


这是因为日语是一种以"主题"为驱动的语言。大多数日语对话一开始会先设定正在谈论的内容，然后每说一句新的话，都会添加更多与主题相关的细节。当焦点转移时，我们就提出一个新的主题来改变主题。能够识别并追踪主题如何变化，是很好地"解析"句子的基础。

<pre>
中文："我吃了一个苹果，然后喝了点水。你做了什么？"
日语："<b>说到我</b>，苹果吃了。之后，水喝了。<b>说到你</b>呢？"
</pre>

这听起来像颠三倒四的原始人说话，但那只是因为用中文来表现日语的结构实在是太滑稽了。这是整本指南中唯一一个我们会写出不自然的中文来与日语作比较的例子。你不应该用这种方式去思考日语。你需要用日语来思考日语，因为日语不是中文，也不是英语。
