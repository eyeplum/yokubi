# い形容词

日语的形容词主要分为两大类。别担心，它们没有动词那么复杂。其实相当简单直接。

这两类是い形容词（形容詞）和な形容词（形容動詞）。

い形容词的表现类似于动词，可以活用。而な形容词的表现则像名词（而且它们通常也可以当名词用）。我们会在后面讲解な形容词。

下面是一个い形容词的实际用例。

<pre>
<b>赤い</b>火
红色的火
</pre>

い形容词之所以与动词相似，是因为它们可以活用。

要用い形容词来说某个名词是/具有某种性质，你可以直接用这个形容词构成一个"A 是 B"类型的句子，就像这样：

<pre>
火が赤い
火是红的。
</pre>

你**绝对不能**在后面加上だ：

<pre>
*火が赤いだ
</pre>

这是**非常**错误的，不值得给出翻译。

不过，在这里接です是可以的，但在这种用法中它并不充当系词。它只是增加礼貌，不带任何含义。这是だ和です的第一个主要区别。当です不接在名词后面时，它只是一个礼貌标记。

<pre>
火が赤い
火是红的

火が赤い<b>です</b>
火是红的（礼貌）
</pre>

除了です之外，也有一些其他句式会在い形容词后面加上だ，但它们都是特定的固定表达。如果你看到了不要惊讶，但现在不必担心。

和动词一样，你也可以对い形容词进行活用。你可以把い换成かった或くない，来构成过去形或否定形：

<pre>
火が赤<b>かった</b>
火<b>曾经</b>是红的。

火が赤<b>くない</b>
火<b>不</b>红。

火が赤<b>くなかった</b>
火<b>当时不</b>红。
</pre>

形容词いい是一个例外，它变成よい -> よかった / よくない。

由于动词中的ない本身也表现得像一个い形容词，所以你可以像活用い形容词那样活用它，从而延续活用链，构成我们前面提到的那种长串动词。

<pre>
見<b>る</b>
看（一段动词普通形）

見<b>ない</b>
不看（否定）

見<b>なかった</b>
没有看（否定，过去）
</pre>

把い换成さ，可以把形容词变成抽象名词。还有其他方法可以做到这一点，但さ是迄今为止最常见的。

<pre>
大き<b>い</b>
大的（形容词）

大き<b>さ</b>
大小/尺寸（名词）
</pre>
