# 用だ和です表示存在状态

我们从"A 是 B"这种形式的句子开始。日语有两个基本的"是"。这类词的语法术语叫做"系词"（copula）。系词之所以有专门的术语，是因为它们是一种特殊的、类似动词的东西。

日语中的两个系词是だ和です。です比だ更礼貌。虽然两者都是系词，但它们的用法可以很灵活，有时甚至是可选的；你可以把它们完全省略，而句子仍然隐含着"A 是 B"这样的关系。特别是だ，在现代日语的口语句子末尾通常会被省略。

与中文和英语不同，表示存在状态的词放在你用来描述某样东西的词的**后面**，而不是前面。我们会看到，这一点适用于日语中的大多数修饰词：它们作用于它们**左边**的词。

<pre>
ペンだ。
这是一支笔。

ネコです。
这是一只猫。
</pre>

だ和です的区别一般在于礼貌程度和正式程度。需要记住的一点是，虽然です是だ的礼貌版本，但两者并不总是可以互换的，而且它们有很多不同的用法。你不能总是随意地用だ替换です（反之亦然）。你会在以后的课程中学到其中一些用法。

以后你还会看到です被用在中文或英语里不会用"是"的地方。这是因为它甚至可以只充当一个没有附加含义的填充词。

要表示某样东西*不是*，我们把だ变成ではない，把です变成ではありません。在口语中，では会含糊地连读成じゃ，所以じゃない和じゃありません更常见。我们会在以后的课程中看看这个では的作用。ではありません还有另一种替代说法，就是在ではない/じゃない后面加上です，意思是一样的。

<pre>
人じゃない
不是人

本じゃないです 或 本ではありません
不是书（礼貌）
</pre>

日语有两种基本的时态：普通时态和过去时态。由于词典是以普通时态来收录动词的，所以它有时也被称为"辞书形"。在这里，"形"和"时态"可以互换使用。

だ的过去形是だった。です的过去形是でした。

<pre>
オレだった！
是我！（随意）

そうでした
是那样的。（礼貌）
</pre>

辞书形通常被称为现在时或非过去时。重要的是要记住，它可以用在很多场合。现在时和非过去时都是合理的名称，但不要把名称当作规则，有时名称会让人困惑。本指南会交替使用这些名称。

普通形和过去时通常与英语的现在时和过去时相对应，但它们的使用场合并不完全相同。只要记住，英语和日语使用时态的方式往往非常不同。中文的动词没有时态变化，所以更要注意不要用中文的思维去套日语的时态。

在日语中，关于将来的普通陈述大多数时候使用普通形。这就是"非过去"这个名称的由来。

有时过去时也可以用于已经完成的事情，比如"已经变成"，即使它们只是假设、还没有发生。你可能还会听到它被称为"完成时"或"完成形"。
