# て形

如果觉得这一课很难，不用担心。我们只是在讲基础知识，现在还不要求你把这里的概念内化。

有一种动词形态以て结尾。这种动词形态主要有两种用法：

- 把动作或陈述串联起来；
- 为动作或陈述增添额外的语感。

把过去时的た换成て，就构成了て形。要记住，这并不是某种次要的过去时。て形本身并不包含任何"时态"的概念。它不会告诉我们句子是过去还是现在。

<pre>
殺<b>して</b>　切<b>って</b>　買<b>って</b>　死<b>んで</b>　食<b>べて</b>
</pre>

<div class="warning">
五段动词行く是一个例外，它的て形是行って，<b>而不是</b>行いて。
</div>

形容词也可以有て形。方法是把い变成くて。

|               |                |
|---------------|----------------|
| 赤<b>い</b>   | 赤<b>くて</b>  |
| 怖<b>い</b>   | 怖<b>くて</b>  |
| 面白<b>い</b> | 面白<b>くて</b>|
| い<b>い</b>   | よ<b>くて</b>  |

<div class="warning">
形容词いい是一个例外，它变成よくて。
</div>

这同样适用于否定形的活用，我们也正是用这种方法把て形用在否定的动词上。

|          |            |
|----------|------------|
| 赤くな<b>い</b> | 赤くな<b>くて</b> |
| 食べな<b>い</b> | 食べな<b>くて</b> |

我们已经见过"A 是 B"和"A 做 B"类型的句子。随着て形的引入，我们将第一次看到"A 做 B，然后 D 做 C"类型的句子。在最基本的句法层面上，AてB 的意思是"A 发生了，然后 B"。它既可以表示时间上的先后顺序，也可以表示原因 -> 结果的关系。它让我们能够构造出含有多个依次排列的动词的更长的句子。注意，前后两部分的主语不必相同。

<pre>
察しがよく<b>て</b>助かる
你这么善解人意，真是帮了大忙。（字面意思：你直觉很好，这帮了我）
</pre>

注：て后面加不加逗号都没有关系。逗号在日语中一般没有语法作用，但它可以让句子更容易解析。

陈述句察しがよくて后面接着陈述句助かる。助かる并不是在修饰よくて。而是第一个陈述为第二个陈述设定了背景。在日语中，先构造一个陈述，接着用て形活用，然后再加上一个描述你对第一个陈述的主观感受或情绪的陈述，是很常见的。你感到得救了（助かる），是因为对方具有察しがいい这种品质。

<pre>
遅くなっ<b>て</b>すみません
对不起，我来晚了（字面意思："我晚了，我很抱歉"）
</pre>

在常见的搭配〜てすみません中，て前面的部分表示道歉的原因。

<pre>
彼女の目を見<b>て</b>、頷いた
我看着她的眼睛，<b>然后</b>点了点头
</pre>

在这个例子中，て只是把陈述串在一起，构成一个简单的动作序列。如前所述，て形不提供任何过去时或现在时的概念。时态是由序列中最后一个动词来传达的。頷いた是过去形，所以我们可以认为整个陈述都是过去时。

有时て形可以让动词充当主题。这样一来，它看起来就像一个名词。它并不是真正的名词，只是在这种情况下看起来像而已。在这种用法中，它后面常常接助词は。

<pre>
腹が減っ<b>ては</b>戦はできない
饿着肚子是没法打仗的。
</pre>

ない的て形なくて常常带有"没有 X，所以 Y"的语感。但这只是一种语感，只是它的可能用法之一。

<pre>
早く起き<b>なくて</b>仕事に遅れた
我没有早起，上班迟到了。（原因）
</pre>
