# 助词与语法格

我们来看看更复杂的"A 做 B"类型的陈述句。我们会在后面的课程中介绍动词和活用，所以这里用到的例句只作为一个大致的参考，不要试图去拆解它们。

要理解"A 做 B"类型的句子，我们首先需要介绍"助词"以及宽松语序的概念。

日语使用"助词"（助詞）——一种类似于介词的东西——来定义词语与句子其他部分之间的关系。日语的助词放在它所修饰的短语或词的后面，而不是前面。我们说助词"附着"在它左边的词上。我们在上一课已经见过类似助词的东西了：系词だ。

在中文和英语中，我们通过语序来理解每个词在句子中所扮演的角色：主语、动词、宾语。

这些角色被称为"格"（case），每一个角色都是一个特定的"格"。日语用助词来表示这些角色，这就是为什么它们常被称为"格助词"。当我们想说某个助词所附着的词在句子中承担了某个角色时，我们就说这个助词"标记"了这个角色。

日语有一个默认的语序，如果意思可以从上下文中推断出来，有时甚至可以省略助词，但一般来说，使用助词是常态。有些词也可以不带助词"自由地"存在于句子中，我们会在后面的课程中看看它们。

记住：这些翻译只是为了演示。这里的句子和翻译只是用来说明，而不是用来教学的。由于日语不明确表示复数，其中很多句子既可以指一个东西，也可以指许多东西，正如[第 2 课](./Lesson2.md)中所解释的那样。

<pre>
ネコ<b>が</b>サカナ<b>を</b>食べる
一只猫吃一条鱼。
</pre>

在这里，が把ネコ标记为主语。を把サカナ标记为直接宾语。然后动词放在句子的末尾。像"吃"这样的动词，其主语是进行吃这个动作的东西，宾语是被吃的东西。

正如[第 0 课](./Lesson0.md)中介绍的那样，比起明确地标记主语或宾语，先引出一个"主题"更为常见。为此，日语使用"主题标记"助词は，它的字面意思就是"这就是我要说的东西"。大多数语法资料都会把は和が作比较。之所以这样做，是因为有时使用が会不自然，你必须改用は，或者干脆不说出主语。但不要被误导，は的作用比作为が的替代品更加广泛。有时它在句子中取代が，把主语作为主题引出；但有时它也可以把宾语标记为主题。在这种情况下，被取代的是を所标记的东西。如下例所示。

<pre>
サカナ<b>は</b>ネコ<b>が</b>食べる
鱼啊，猫会吃它。

ネコ<b>は</b>サカナ<b>を</b>食べる
猫啊，它吃鱼。
</pre>

由于默认的预期是先引出一个主题，然后用句子的其余部分来描述它，所以当我们在本该出现主题的地方故意明确地使用非主题助词（比如が）时，就会对句子的那一部分施加额外的强调。这种"强调"是在が作为主语标记的功能之**外**附加的，而不是取而代之。が带有这种语感很常见，但并不是所有的が都是强调标记，有时它们只是中性的主语，而主题是别的东西。

比较下面的句子：

<pre>
ネコ<b>が</b>サカナ<b>を</b>食べる
吃鱼的是猫。

ネコ<b>は</b>サカナ<b>を</b>食べる
猫吃鱼。
</pre>

英语用冠词和一些奇特的句型来表达这种强调，中文则常用"是……的"之类的句型，但日语需要依靠助词，因为语序在语法上并不重要。

另一个区别是，主题は通常被认为是对话中已经引入过的东西（类似于英语中的"the"和"a"的区别），或者是作为一般陈述而被普遍理解的东西。

例如，下面的翻译都是正确的。上下文会清楚地表明哪一种最合适。

<pre>
ネコ<b>は</b>魚<b>を</b>食べる
猫吃鱼（泛指猫）
那只猫吃鱼（我们刚才说的那只猫）

ネコ<b>が</b>魚<b>を</b>食べる
有一只猫在吃鱼（某一只随便的猫）
吃鱼的是那只猫（一群猫中特定的一只）
</pre>

本课只是浅尝辄止地介绍了は和が可以承担的各种角色。不要试图把它们当作普遍真理来记忆，只要在语境中看到这些句子时，能意识到它们所传达的大致感觉和含义就可以了。
