# 用の表示所属和属性

の是一个助词。它是所属标记，也是属性标记。这里的"属性"是指某样东西是另一样东西的属性，就像电子游戏里的属性一样，比如"火焰剑"中的"火焰"。这种关系总是很直接的。

<pre>
私<b>の</b>ネコ
我的猫

君<b>の</b>X
你的 X。

ネコ<b>の</b>先
猫的前方

男<b>の</b>子
男孩（比喻义，男性的孩子）
</pre>

如果你搞糊涂了，记住の最简单的方法是：它就像中文的"的"，而且方向也一样。

<pre>
夜<b>の</b>人
夜晚的人
</pre>

有时"的"也会让人困惑，这时你就要记住"属性"这个概念。

<pre>
夜<b>の</b>海
夜晚的海

海<b>の</b>夜
海上的夜晚
</pre>

の简直就是整个日语中最常见的一个词，所以一定要好好记住它！

<pre>
彼女<b>の</b>子供<b>の</b>名前だ。
这是她孩子的名字。
</pre>
