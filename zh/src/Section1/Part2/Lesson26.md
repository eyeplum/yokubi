# 用たい和ほしい表达意志和愿望

在本课中，我们将学习在日语中表达愿望或意图的三种方法。

"意志形"おう/よう表示你想要或将要做某事，或者像"我们做 X 吧"那样邀请别人一起。它也用于表示意志性动作的复合句式中。五段动词的意志形是 -ou，一段动词的意志形是よう。它读作"长音 o"，而不是お加う。

<pre>
行こう
我们走吧。

行こうか
我们去怎么样？

食べようと思う
我想我要吃了。
</pre>

注：我们会在后面的章节中学习と与思う的这种用法，现在不必太担心。

です的意志形是でしょう，だ的意志形是だろう。它们通常"引出一个想法"，比如推测或可能性。

<pre>
いいでしょう
挺好的，你不觉得吗？

犬だろうと、猫だろうと、なんでも問題ありません
不管是狗还是猫，什么都没问题。
</pre>

表达愿望的第二种方法是たい。たい是一个类似い形容词的补助成分，接续方式与ます相同。

<pre>
死にたい
我想死。

アイスが食べたい
我想吃冰淇淋。
</pre>

在最后一个例句中，用を也是可以的。在が和を的问题上，たい的表现与可能动词相似。が或を都可以用来标记愿望的对象/目标，不过不同的动词可能会对其中之一有特定的偏好。不要试图去记这个，只要知道它的存在，并且它是正确的日语就行了。

表达想要的最后一种方法是用欲しい，这是一个い形容词。

<pre>
アイスがほしい
我想要冰淇淋
</pre>

注：与たい类似，ほしい也属于那类古怪的形容词，其中が标记愿望的对象，有时可以换成を。然而，与たい不同的是，をほしい非常不规范，也不太常见。你可能仍然会看到它，但很多人会认为这是别扭的日语。最好避免使用。

ほしい的另一个特点是，它可以作为补助成分接在动词的て形后面，用来发出委婉的命令或请求。

<pre>
その話はやめてほしい
我希望你别再说那件事了
</pre>

它听起来可能比てください更客观、更间接一些，也可以用来从你的角度提供一般性的建议，说明你希望某人怎么做。需要记住的重要一点是，谈论自己时用がほしい，谈论别人时用てほしい。
