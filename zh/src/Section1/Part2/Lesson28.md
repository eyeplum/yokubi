# 动词复习

我们终于把五段动词的所有基本词干都见过了，所以现在是复习所学内容的好时机。请不要试图去背这些。知道这些概念的存在就足够了。如果你看得两眼发直，放松一下。如果做不到，那就继续往下学。

这里给出的名称只是对各种形态的简单描述/提醒，并不是正式的语法名称。为了满足好奇的读者，这里也会给出日语名称及其相应的正式术语，但你不需要记住它们。如果在本指南的其余部分提到某个词干或形态，会使用简单的中文描述，而不是日语名称。

| 形态            | 名称                   | 日语术语                                   |
|-----------------|------------------------|-------------------------------------------------|
| 書**か**(ない)  | 否定词干          | 未然形                          |
| 書**き**(ます)  | ます词干              | 連用形                      |
| 書**く**        | 普通形/辞书形  | 終止形 或 連体形   |
| 書**け**(る/ば) | 可能词干         | 已然形 或 仮定形   |
| 書**け**        | 命令形        | 命令形                          |
| 書**こう**      | 意志形        | 意向形                          |

记住，对于五段动词，过去形和て形的活用有特殊的规则。例如，对于か行，き会变成い：

<pre>
書<b>い</b>て
書<b>い</b>た
</pre>

对于一段动词，词干保持不变，所以要简单得多，只需替换る即可：

<pre>
食べ(ない) 否定形
食べ(ます) ます形
食べる 普通形/辞书形
食べ(られる/れる) 可能形
食べ(れば) 条件形/ば形
食べ(ろ) 命令形
食べ(よう) 意志形
食べ(て) て形
食べ(た) 过去形
</pre>

还有两个不规则动词する和くる：

| 形态       | する      | くる     |
|------------|-----------|----------|
| 否定   | しない    | こない   |
| ます词干  | し(ます)  | き(ます) |
| 普通      | する      | くる     |
| 可能  | できる    | これる   |
| ば词干    | すれば    | くれば   |
| 命令 | しろ/せよ | こい     |
| 意志 | しよう    | こよう   |
| て形    | して      | きて     |
| 过去       | した      | きた     |

另外提醒一下，五段动词行く的て形和过去时是不规则的：行って/行った。
