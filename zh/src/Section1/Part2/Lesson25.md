# 可能形与できる

可能形的作用是让人们能够说某件事"可以做到"。对于五段动词，把 u 换成 e，再加上る。也就是"u" -> "eru"。对于一段动词，它与被动形的活用完全相同。是的，这很让人困惑。它是如此令人困惑，以至于有时你可能会遇到一些句子，其中一段动词究竟是被动形还是可能形并不清楚，或者是故意模棱两可的。你只能凭感觉去体会。

<pre>
食べ<b>られる</b>（或 食べ<b>れる</b>（！））
能吃

殺<b>せる</b>
能杀

死<b>ねる</b>
能死

飲<b>める</b>
能喝
</pre>

你可能已经注意到了，食べれる被列为食べられる的一个可接受的变体，旁边还带着一个大大的 **！**。在口语/非正式的日语中，通过去掉ら这个音节来缩短一段动词的可能形是很常见的（这叫做ら抜き，"去ら"）。这并不"规范"，不应该在正式场合或书面语中使用，但在随意的口语中相当常见。并不是每个一段动词都可以这样做，但对于哪些可以、哪些不可以，并没有明确的规则。这取决于个人喜好，所以不要试图去学这条规则。只要知道它的存在，并学会识别它就行了。

对于不规则动词する，我们使用另一个动词できる作为它的可能形。这是一个例外，所以只需要照此记住即可。

<pre>
昨日は勉強<b>できなかった</b>
我昨天<b>没能</b>学习
</pre>

为了让可能/被动的二重性更加令人困惑，我们需要谈谈日语中可能动词所带有的一个英语中没有的特殊之处。

说到可能形，他动词中"主语"和"宾语"的概念在语法上可能会变得模糊。我们来看一个例子：

<pre>
私<b>は</b>ピザ<b>を</b>食べる
我吃披萨（非可能形，标准形式）

私<b>は</b>ピザ<b>が</b>食べられる
私<b>に</b>ピザ<b>が</b>食べられる
私<b>は</b>ピザ<b>を</b>食べられる
我能吃披萨（可能形，标准形式）
</pre>

这是怎么回事？这三种说法都是正确的，意思也大致相同。此外，根据语境和周围的短语，这些例子中的は也可以是が（是的，你甚至可以说私がピザが食べられる，一个带两个が的句子）。

你只需要记住，对于可能动词，が*也*可以用来标记动作的宾语，而不仅仅是主语。而且在这些句子中，主语有时可以用に来标记。有些人认为像上面例子中那样使用を是不规范的，但这是极其主观的，而且你会如此频繁地看到它，以至于认为它不规范的只有那些对着云朵大喊大叫的老头子。を的版本往往在关系从句或非常长而复杂的句子中更常见。

还有另一种构成带有可能含义的短语的方法，那就是在普通形的动词后面直接接上ことができる。我们会在后面的课程中看到这个こと是什么意思，但现在你应该把ことができる当作一个整体。

<pre>
俺は答える<b>ことができなかった</b>。
我<b>没能</b>回答。
</pre>

ことができる和普通的可能形活用之间的区别极其微小，常常难以察觉。ことができる可能听起来稍微正式一些，因为它更冗长，但这不值得担心。你可以认为它们基本上是可以互换的。
