# 用の提问与表示解释的のだ

另一个类似于か的疑问助词是の。用の提出的问题所带有的言外之意与用か提出的问题截然不同。我们稍后再解释其中的语感，先把注意力放在结构上。

要用の提问，在随意形中，只需在动词和い形容词的末尾加上の，在名词和な形容词后面加上なの（不带だ）。问号是可选的。

|                 |                  |
|-----------------|------------------|
| 学生(だ)        | 学生なの？       |
| 他是学生 | 他是学生吗？ |

<br />

|              |               |
|--------------|---------------|
| 普通(だ)     | 普通なの？    |
| 这很普通 | 这很普通吗？ |

<br />

|            |             |
|------------|-------------|
| 寒い       | 寒いの？    |
| 很冷 | 很冷吗？ |

<br />

|            |                |
|------------|----------------|
| 魚を食べる | 魚を食べるの？ |
| 我吃鱼 | 你吃鱼？  |

在礼貌形中，我们只需在の后面加上ですか，即使是动词句也是如此。在口语中，这常常被含糊地说成んですか，而不是のですか

| 随意         | 礼貌               |
|----------------|----------------------|
| 学生なの？     | 学生なんですか？     |
| 普通なの？     | 普通なんですか？     |
| 寒いの？       | 寒いんですか？       |
| 魚を食べるの？ | 魚を食べるんですか？ |

の也可以用来结束陈述句，而不是疑问句。在这种用法中，语调应该能清楚地表明它不是一个问题，而且结构也略有不同。

要构成の陈述句，在随意的日语中，你要应用与の疑问句相同的规则，但改为以のだ（或んだ）结尾：

<pre>
学生なんだ
是学生

普通なんだ
很普通

寒いんだ
很冷

魚を食べるんだ
我吃鱼
</pre>

而在礼貌形中，这与のですか疑问句相同，只需去掉です后面的か即可。

<pre>
学生なんです

普通なんです

寒いんです

魚を食べるんです
</pre>

以だ结尾的陈述句可能听起来很生硬，所以人们在随意的陈述句中常常会在んだ后面加上よ或ね来缓和语气。我们会在后面的章节中学习句末助词よ和ね。

你也可以不带だ，直接用の来结束の陈述句，但这听起来比较女性化，所以要小心。

现在我们来谈谈这些の疑问句和陈述句所带来的语感。

从表面上看，の疑问句和のだ陈述句看起来都和不带の(だ)的普通疑问句和陈述句相似，但这个の(だ)的存在为它们增添了某种"解释性"或"追问性"的语气。

当你用の？或んですか？提问时，你在暗示你期望对方为你所问的事情提供解释、借口或理由。你通常在想要澄清某件事时才会问这样的问题。

<pre>
メアリーさんは学生なんですか？
玛丽是学生，是这样吗？
</pre>

当你根据谈话中透露出来的一些间接证据得出结论，认为玛丽可能是学生，但又不太确定时，你可能会这样问。你在寻求确认。

<pre>
猫が好きなんですか？
你是喜欢猫吗？
</pre>

当你看到某人开心地和猫玩耍，想要确认一下时，你可能会这样问。

为了更清楚地说明，我们来比较一下这两个句子

<pre>
何をしてる？
你在做什么？

何をしてるの？
你到底在<i>干什么</i>？
</pre>

注：第二句中的"干什么"用斜体强调，以表示语气。

你可以想象第一句是在电话里问朋友在忙什么时使用的，只是因为你好奇，想找个话题聊聊。然而，第二句听起来更具追问性，甚至可能带有攻击性，你可以想象当你看到有人正在撬你的车、被你当场抓住时会这样说。就像"喂，你到底在干嘛？"你在期待、甚至是要求一个解释。

同样地，当我们以带有解释性语感的方式陈述时，我们会用んだ。就像用の？提问是在寻求澄清一样，用んだ陈述是在提供说话者想让听者知道的解释或额外信息。

んだ有一些常见的用法，但我们不会在这里全部讲解，因为这是一个非常微妙、难以解释的话题，超出了入门指南的范围。你会通过沉浸和接触看到它们被大量使用。只要知道这个基本区别就可以了：

<pre>
私は日本人です
我是日本人

私は日本人なんです
其实我是日本人（你之前不知道，但我是日本人）
</pre>

前者听起来像一个简单的、就事论事的陈述。你在陈述关于自己的某件事。而后者听起来像是你在解释某件事，或者试图澄清某种情况。它的具体含义取决于语境，但传达出来的语感是，你觉得有必要通过陈述这个事实来提供解释或澄清。

<pre>
世の中にはいろんなことがある<b>んだ</b>
这世上什么样的事都有（我跟你说）

それからのことはよく覚えていない<b>んだ</b>
那之后的事我记不太清了（我在为自己找借口）

そんなことはどうでもいい<b>んだ</b>よ
我跟你说了，那种事无所谓（带有解释性语气的额外强调）
</pre>

んだ有一个值得指出的特定用法：说话者意识到某个新信息时常常会用它。这常常以过去时的形式使用，以突出从"不知道"的状态到"知道"的状态的转变。

<pre>
へー、学生<b>だったんだ</b>
哦，原来是学生啊。

ああ、そういうこと<b>だったんだ</b>
啊，原来是这么回事（字面意思："啊，原来是那样的事情"）
</pre>

它也可以作为某种固定短语使用，告诉听者你在跟着对话的思路。

<pre>
ふーん、そう<b>なんだ</b>
哦——，这样啊。
</pre>

用の提出的问题，常常用以のだ结尾的陈述句来回答。

注：有时你可能会看到以のだ结尾的の疑问句，末尾常常带有？，语调会清楚地表明这是一个问题。它与普通的の疑问句没有太大区别，但听起来更强烈，也可能更具攻击性：何してるんだ？！
