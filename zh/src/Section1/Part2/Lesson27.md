# 用四种条件形表达"如果"和"……的时候"

日语条件句的顺序是先说条件，再说结果动作。条件句是我们把两个"A 做 B"类型的句子连接成"如果 A 做 B，那么 C 做 D"这种结构的一种方式。显然，像"如果 A 是 B，那么 C 做 D"这样的结构或任何其他组合也都是可以的。

如果事情简单到只用一种条件形就能应付，那就太好了，但日语的乐趣就在于，说类似的事情有很多种不同的方法，条件句就是其中之一。不幸的是，它们各自都有不同的用法和语感，用中文或英语的语法极难解释，所以你只能依靠直觉和接触。

主要有四种条件形：たら、ば、と和なら。它们都落在"如果"和"……的时候"这一范围之内，有时甚至是"就在……时"（比如"就在我醒来时，我听到外面有奇怪的声音"）。实际上还有更多构成条件句的方法，但这四种是本课的主要内容。

和往常一样，不要试图完美地记住这一课，只要在遇到时能认出每个例子，并知道它们大致表示"如果"或"……的时候"就行了。

我们要看的最简单的条件形是ば形，它把动词变成条件。其活用方法是把动词末尾的 u 变成 e，然后加上ば。基本上，对于五段动词，把 u 换成 e；对于一段动词，在词干后面加上れ。

<pre>
見<b>れば</b>死ぬ
<b>如果</b>你看了就会死。

お前を殺せ<b>ば</b>、すべてが終わる。
<b>只要</b>杀了你，一切就都结束了。
</pre>

ば暗示条件足以使结果发生。它是真正逻辑上的"如果"。它甚至可以用于某些请求，比如"如果你要迟到，打个电话就行，我会处理好一切"。然而，ば并不暗示条件最终一定会发生，所以它不能用在像"你来的时候，来找我"这样的句子中。在叙述中，它有时可以表示"发生了 X，然后 Y"，但这种非条件的用法相当有限，在文学作品之外并不常见。

对于系词だ的ば条件形，我们需要把它"展开"成である，然后对其进行活用。

<pre>
普通の人<b>であれば</b>、その命令に逆らうことはできないだろう
如果他是个普通人，他肯定无法违抗那道命令。
</pre>

对于い形容词，我们把い变成ければ：

<pre>
良<b>ければ</b>教えてください。
如果可以的话，请教教我。
</pre>

たら是另一种条件形，在某些用法中与ば相似。然而，与ば不同的是，它的范围更广，带有一系列动作依次发生的语感。它可以用来连接两个事件，这两个事件既可以是纯粹假设性的，也可以是严格时间上的先后顺序。它可以是"如果 A 发生，那么 B"，也可以是"A 发生了，紧接着 B 就发生了"。为了更容易地做出这种区分，在假设意义上的短语中，人们常用もし作为开头词来提示听者。

<pre>
<b>もし</b>敵がい<b>たら</b>私が斬り捨てます
<b>万一</b>有敌人，我会把他们砍倒（假设）

朝起き<b>たら、</b>食堂には誰もいなかった。
早上<b>一</b>起来，食堂里一个人也没有。
</pre>

たら的"一……就……"的用法，在讲述过去发生在你身上的"一次性"事件时很常见，这些事件往往出乎意料。

假设意义上的たら和ば常常可以互换。甚至还存在地区差异，日本某个地区的人可能更喜欢其中一个，反之亦然。这就是为什么你不应该问"为什么这个人用たら而不用ば？"这样的问题。接受它就好。

たら还有另一种特殊用法，通常直接放在名字后面，形式是ったら。这个ったら的意思完全不同，只是作为一个助词，表示恼火的感叹。它不是条件形。

<pre>
もう、お父さん<b>ったら</b>、しっかりしなさい！
真是的，爸爸你啊，给我振作一点！
</pre>

と用来连接两个事件，其中一个是另一个的自然结果，具有很强的先后顺序性。这与たら的时间顺序相似，但它不是标记事件的个别发生（"我做了 X，然后……"），而是用来描述每次都会发生的一般事件（"一旦你做了 X，就……"）。

<pre>
あんまり食べる<b>と</b>太りますよ
<b>如果</b>吃太多，你会发胖的
</pre>

这个と也常用于叙述中，描述一个接一个发生的一系列事件。在这种用法中，它听起来就好像读者无法控制这些事件，只是一个旁观者，看着这些事件在眼前"自然地"发生，就像在看一场表演。

<pre>
少し歩く<b>と</b>、開けた場所に出た。
走了一会儿<b>之后</b>，他们来到了一片开阔地。
</pre>

本课的最后一种条件形是なら。なら是一种严格假设性的条件形。它暗示在陈述所处的假设世界中，条件被假定为真。
这意味着当你说 X なら Y 时，意思接近于"如果我们考虑 X 为真的情况，那么 Y"，但它听起来并不像中文里那么啰嗦。这是一种非常常见的表达方式。

<pre>
行きたい<b>なら</b>一緒に行こう
<b>要是</b>你想去的话，我们一起去吧
</pre>

由于なら的这种特定语感，它是唯一一种第二个从句可以在前一个从句之前发生的条件形。と、たら和ば都不能这样做。

<pre>
運転する<b>なら</b>飲まないで
<b>如果</b>你<b>要</b>开车，就不要喝酒。
</pre>

飲む这个动作必须发生在運転する这个条件之前，因此说话者**假定**在这条建议（飲まないで）所处的假设世界中，運転する将会发生。

有时なら会以ならば的形式出现。意思是一样的，但感觉更书面一些。

对于动词和い形容词，有时可以在动词和なら之间加上の。这可以带来一些额外的语感（类似于のだ中表示解释的の），但你不必记住这个。只要记住，带の的版本听起来可能更书面、更正式。

<pre>
そんなに知りたい<b>のなら</b>、教えてあげましょう。
<b>既然</b>你那么想知道，我就告诉你吧。

そんなに知りたい<b>なら</b>教えてやる。
<b>既然</b>你那么想知道，我就告诉你
</pre>
