# こそあど指示词

指示词是表示"这""那"之类意思的词。

日语在这方面与英语有两点不同。第一，它的指示词规则得多；第二，它的指示词对应三个"位置"，而不是两个。中文也和英语一样，只有"这"和"那"两个位置。这一点用例子来展示比解释更容易，所以我们来看看例子：

<pre>
<b>こ</b>れ
这个（离说话者近的东西）

<b>そ</b>れ
那个（离听话者近的东西）

<b>あ</b>れ
那边那个（离说话者和听话者都远的东西）

<b>ど</b>れ
哪个

<b>これ</b>はペンです
<b>这</b>是一支笔

<b>それ</b>は猫ですか？
<b>那</b>是猫吗？（猫离听话者近）

<b>あれ</b>は何？
<b>那</b>是什么？（指着离你和听话者都远的东西）

<b>どれ</b>がいい？
<b>哪个</b>好？
</pre>

上面这四个词是"指示代词"。其中两个在中文里都译作"那个"，但它们在日语中有不同的含义。それ用于离听话者近的东西。あれ用于离说话者和听话者都远的东西。

如果你还没注意到其中的规律——正如本课标题所指出的——我们有时会把它们统称为こそあど，因为它们之间只有第一个假名音节不同。

尽管存在两种"那"的区分，但这些词的使用方式与它们在中文里的使用方式非常相似。

还有另一组非常相似的こそあど指示词，它们在语法上的作用不同，但在翻译成中文时很难解释，所以我们先来看看例子：

<pre>
この&lt;名词&gt;
这个&lt;名词&gt;

その&lt;名词&gt;
那个&lt;名词&gt;

あの&lt;名词&gt;
那边那个&lt;名词&gt;

どの&lt;名词&gt;
哪个&lt;名词&gt;
</pre>

这些词不能单独存在，**必须**附着在它们后面的名词上。它们的意思与另一组相同，但用法略有不同。

想象你正拿着一本书，想说"这是一本书"。"书"是句子的焦点，所以你会说これは本です。你只是用系词简单地陈述"这 = 书"。然而，如果你想说**关于**这本书的某件事，你就会改说この本は面白いです。**这本书**很有趣。"这"和"书"变成了一个单位。在中文里，"这是一本书"和"这本书很有趣"用的都是"这"，但在日语中一个用これ，另一个用この。

所有其他带の的こそあど词也是如此。

还有很多其他的词也属于こそあど这种结构。我们不会在这里全部讲解，但它们通常相当规则，都遵循以下规则：

<pre>
こ = 离说话者近
そ = 离听话者近
あ = 离两者都远
ど = 疑问词
</pre>

あ是唯一一个发音稍有不规则的行，但你遇到时就会知道了。下面是一些例子：

|                   |                    |            |         |
|-------------------|--------------------|------------|---------|
| ここ              | そこ               | あそこ     | どこ    |
| 这里（这个地方） | 那里（那个地方） | 那边     | 哪里？  |

<br />

|                 |                 |                |                  |
|-----------------|-----------------|----------------|------------------|
| こちら          | そちら          | あちら         | どちら           |
| 这个方向  | 那个方向  | 那边的方向 | 哪个方向？ |

<br />

|                 |                |                |                  |
|-----------------|----------------|----------------|------------------|
| こう            | そう           | ああ           | どう             |
| 这样  | 那样 | 那样 | 怎样？ |

<br />

|           |           |            |            |
|-----------|-----------|------------|------------|
| こいつ    | そいつ    | あいつ     | どいつ     |
| 这家伙 | 那家伙 | 那家伙  | 哪个家伙 |

注：こちら这一组也可以在礼貌的场合用作指代他人的礼貌方式，因为它增加了间接性。另一方面，こいつ这一组常常听起来很粗鲁，所以不要叫别人こいつ。

就像在中文里一样，物理距离并不是这些词的唯一决定因素。它们也可以用来指代时间上遥远的事物。它们甚至会受到说话者和听话者对话题的熟悉程度的影响。对话中较早提到的东西可能会被称为あの〈东西〉，而刚刚提到的东西则更可能被称为その〈东西〉。就像在中文里我们有时不知道该说"这"还是"那"一样，即使在日语中人们的看法也并不总是一致，所以在这些情况下，区分并不总是那么严格。
